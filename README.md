 🚀 **Core Portfolyo Projesi**

 Bu proje, ASP.NET Core MVC kullanılarak katmanlı mimaride geliştirilmiş dinamik bir kişisel portfolyo ve içerik yönetim sistemidir. Sistem; sitedeki tüm içeriklerin yönetildiği **Admin Paneli**, kullanıcıların mesajlaşıp duyuruları takip edebildiği **Yazar Paneli** ve ziyaretçilerin portfolyoyu inceleyebildiği **Vitrin Arayüzü** olmak üzere modüler bir yapıdan oluşmaktadır.

🌐 **Vitrin (Ana Sayfa) Özellikleri**
---

• **Hakkımda:** Açıklama metni, yaş, iletişim bilgileri ve profil görseli veritabanından dinamik olarak listelenir.

• **Hizmetler:** Sunulan hizmetler ana sayfada listelenir.

• **Yeteneklerim:** Yetenekler, yüzdelik ilerleme çubuklarıyla görselleştirilir.

• **Projelerim:** Projeler görselleriyle birlikte galeri düzeninde sergilenir.

• **Deneyimlerim:** İş ve staj deneyimleri tarih bilgileriyle birlikte sıralanır.

• **Referanslar:** Referans yorumları ana sayfada gösterilir.

• **İletişim:** Ziyaretçiler iletişim formu üzerinden mesaj gönderebilir, iletişim bilgileri dinamik olarak görüntülenir.

🔑 **Admin Paneli Özellikleri**
---

• **Veri Yönetimi:** Hakkımda, hizmetler, yetenekler, projeler, deneyimler, referanslar ve iletişim bilgileri üzerinde ekleme, silme, güncelleme ve listeleme işlemleri gerçekleştirilebilir.

• **Proje Yönetimi:** Projeler; başlık, görseller, proje bağlantısı, fiyat, tamamlanma oranı ve platform bilgileriyle eklenip güncellenebilir.

• **Mesaj Modülü:** Yazarlardan gelen mesajlar gelen ve giden kutusu olarak listelenebilir, detayları görüntülenebilir, silinebilir ve panel üzerinden yeni mesaj oluşturulabilir.

• **İletişim Mesajları:** Ziyaretçilerin iletişim formundan gönderdiği mesajlar panel üzerinden takip edilebilir.

• **Grafikler:** Sistem verileri grafikler aracılığıyla görselleştirilebilir.

• **Rol Bazlı Yetkilendirme:** Admin paneline yalnızca yetkili kullanıcılar erişebilir.

👤 **Yazar Paneli Özellikleri**
---

• **Kayıt ve Giriş:** Kullanıcılar sisteme kayıt olup giriş yapabilir.

• **Dashboard:** Gelen mesaj, duyuru, toplam kullanıcı ve yetenek sayıları istatistik kartlarıyla gösterilir.

• **Mesajlaşma:** Yazarlar diğer kullanıcılar ve admin ile mesajlaşabilir, gelen ve giden kutuları üzerinden mesajlarını takip edebilir.

• **Duyurular:** Admin tarafından yayınlanan duyurular listelenebilir.

• **Profilimi Düzenle:** Yazar ad, soyad, şifre ve profil resmi bilgilerini güncelleyebilir.

📌 **Projede Kullanılan Teknolojiler**
---

 ✅ ASP.NET Core MVC (.NET Core 5)
 
 ✅ Microsoft SQL Server
 
 ✅ Entity Framework Core (Code First)
 
 ✅ ASP.NET Core Identity (Kayıt, Giriş ve Rol Yönetimi)
 
 ✅ Authentication / Authorization / Validation
 
 ✅ LINQ Sorguları
 
 ✅ Repository Design Pattern
 
 ✅ Katmanlı Mimari Prensibi
 
 ✅ Areas, View Components ve Partial Views
 
 ✅ Dosya Yükleme (IFormFile)
 
 ✅ ASP.NET Core Web API
 
 ✅ Bootstrap, HTML5, CSS3
